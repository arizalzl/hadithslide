Jadikan Aplikasi APK Android

Siap di-install di HP dengan penyimpanan draf offline & share langsung ke Galeri

Cara 1 (Terbaik) Compile APK via Capacitor CLI

Simpan file HTML ini sebagai www/index.html di dalam folder proyek baru, lalu jalankan perintah berikut di terminal (membutuhkan Node.js & Android Studio): 

npm init -y
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init "HadithSlide AI" "com.dakwah.hadithslide" --web-dir www
npx cap add android
npx cap sync
cd android && ./gradlew assembleDebug

Hasil file instalasi siap pakai akan muncul di: android/app/build/outputs/apk/debug/app-debug.apk

Cara 2 (Tanpa Coding) Bungkus Instan via PWABuilder
  1. Upload file hadithslide-studio.html (ubah nama menjadi index.html) ke hosting gratis seperti Vercel, Netlify, atau GitHub Pages.
  2. Buka situs pwabuilder.com, masukkan URL aplikasi Anda, lalu klik Package for Stores → Android.
  3. Unduh paket Android dan install file .apk langsung di HP Anda.
